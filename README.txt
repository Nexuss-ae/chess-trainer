Chess Trainer 6.9.5 — Offline & Fast Loading

- After one successful online load, the app shell and required local files are saved for offline use.
- On return visits the saved page opens immediately; online updates happen in the background.
- If there is no saved page yet, the first network attempt gives up after a short wait instead of hanging for a long time.
- Text files are compressed by the server to reduce download time.

Offline setup: open the deployed page while online and leave it open briefly so the offline copy can finish saving. Then try turning off the connection and reloading. Browsers may need one refresh after a new deployment to install the updated offline copy.
