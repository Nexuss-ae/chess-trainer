Chess Opening Trainer 2.6 — Railway upload package

Files:
- Dockerfile
- index.html
- service-worker.js

Quick setup:
1. Extract this ZIP.
2. Create a new GitHub repository.
3. Upload all three files to the repository root and commit.
4. In Railway, create a project and deploy from the GitHub repository.
5. After deployment, open the service Settings > Networking > Public Networking > Generate Domain.
6. Visit the HTTPS address once while online and wait for it to finish loading. The service worker then saves the page for offline use.

Bot Elo values are approximate. No Chess.com rating calibration is claimed.
